矿权日报 Agent

3 个 MCP server + 1 个 Agent client，输入一句「Pilbara 锂矿今日简报」，经真实 stdio 工具调用产出一份带引用源的 Markdown 简报。本页由最新一次 demo 运行离线生成，可直接双击打开。

系统架构

Input
一句请求
→
MCP Client · agent/src
ReAct 循环 / 确定性 planner
→
Output
Markdown 简报 + 引用源
ReAct：配 API key 时模型自选工具与轮次 确定性 planner：无模型也能跑完，结果可复现

Client 通过 McpHub 用 stdio 拉起每个 server（initialize → tools/list → tools/call），把工具目录喂给编排层；所有数字仅来自工具返回值，LLM 只做证据挑选与文字撰写。本次运行编排模式：

三个 MCP Server · 五个工具

mining-news-mcp

● 实时 RSS

聚合 mining.com / australianmining.com.au，30 分钟磁盘缓存，断网降级到本地 fixture。

  • search(query, days, limit)
  • fetch_article(url, max_chars)

mineral-pdf-mcp

◐ 真实解析 + 合成样例

pdfjs-dist 抽文本层，NI 43-101 启发式解析表格式与叙述式资源量披露。

  • extract_resources(pdf_url, max_pages)

lime-price-mcp

○ 确定性合成序列

按 品种+日期 播种、可复现；设 PRICE_API_URL 即零改动切授权行情源。

  • get_price(commodity, date)
  • get_trend(commodity, days)
